# Australian Languages Explorer & Learning Tool

An interactive web application developed for the **CITS1501** project, designed to explore, the rich cultural diversity of Aboriginal and Torres Strait Islander languages in Australia.

---

## Features

1. **Language Explorer**: 
   - Filter languages instantly by Australian regions/territories.
   - Filter by documentation status or search dynamically by language name and AUSTLANG code.
   - Detailed interactive cards with expandable descriptions and regional locations.

2. **Quiz & Learning Mode**:
   - Test your geographic knowledge with an interactive quiz where you must identify the native region of a mystery language.
   - Dynamic score tracking and instant visual feedback.

3. **Analytics & Interactive Map**:
   - Statistical charts showing language distribution across regions and documentation statuses.
   - A global Pydeck-powered interactive map visualizing geolocated languages across Australia with custom tooltips.

---

## Tech Stack

* **Python** (Core logic)
* **Streamlit** (Web framework & UI)
* **Pandas** (Data manipulation & analysis)
* **Pydeck** (Interactive spatial mapping)
